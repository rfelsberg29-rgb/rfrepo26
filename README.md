# Challenge Games

Plain JavaScript browser games — open an HTML file and play. No install, no build step.

## Games

### Rift Hockey
Knock hockey with a twist: **side rifts teleport the puck**, and a **center vortex** can yank it mid-rally. Play vs AI or local 2-player.

Open [`rifthockey.html`](./rifthockey.html) in any browser.

**Controls**
- **You (bottom):** mouse / touch, or `A` `D` · charge smash with click / `Space`
- **Player 2 (top):** `←` `→` · smash with `Shift`
- First to **5** wins

### Curveball — Hangman
Hangman with a sports twist. Guess letters across Sports, Movies, and Fun Stuff before six strikes.

Open [`hangman.html`](./hangman.html) in any browser.

## Clone & play

```bash
git clone https://github.com/rfelsberg29-rgb/rfrepo26.git
open rifthockey.html
# or
open hangman.html
```
